# Thermo Control v2.8.3

Dieses Release behebt ein Validierungsproblem beim Speichern von Räumen (`Ungültige Raumkonfiguration: not a valid option at 'control_mode'`), das nach Frontend-Aktualisierungen auftreten konnte, und härtet die Konfigurationsvalidierung ab.

### Fehlerbehebung & Verbesserungen

- **Gehärtete Schema-Validierung (`extra=vol.REMOVE_EXTRA`)**:
  - `ROOM_SCHEMA` und `DEVICE_SCHEMA` entfernen unbekannte oder zukünftige Konfigurationsschlüssel nun automatisch (`extra=vol.REMOVE_EXTRA`), anstatt das Speichern mit einer Fehlermeldung zu verweigern.
  - Dies verhindert Validierungsfehler, wenn ein Browser-Bundle nach einem Update bereits neuere Felder übermittelt, Home Assistant aber noch nicht neu gestartet wurde.

- **Fehlertolerante Normalisierung von `control_mode`**:
  - Bei der Raumkonfiguration werden leere Werte (`None`, `""`) sowie `room` auf Raumebene automatisch abgefangen und auf den Standard-Regelungsmodus des jeweiligen Heizungstyps zurückgesetzt.
  - Auf Geräteebene (`devices`) werden leere Werte nahtlos zu `"room"` normalisiert (Übernahme des Raummodus).

### Wichtiger Hinweis nach Updates

Wenn Sie Thermo Control über HACS oder manuell aktualisieren, **starten Sie Home Assistant anschließend bitte neu** (**Einstellungen → System → Neu starten**). Erst nach dem Neustart lädt Home Assistant die aktualisierten Python-Module der Integration in den Speicher.
